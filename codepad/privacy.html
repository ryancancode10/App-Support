CodePad Privacy Policy

Last updated: July 23, 2026

CodePad does not collect, store, or transmit any personal data. Period.

What CodePad does

CodePad is a code viewer and editor. It opens files you explicitly select through the iOS document picker, displays them, and — if you choose to edit — saves your changes directly back to the original file. Everything happens on your device.

Data collection

  • No analytics. CodePad contains no analytics or tracking SDKs.
  • No accounts. There is nothing to sign up for or log in to.
  • No servers. We operate no backend. Your files and edits are never uploaded anywhere.
  • No advertising. CodePad shows no ads and shares nothing with ad networks.

File access

CodePad can only access files you explicitly pick through the system document picker. Access is granted per-file by iOS (security-scoped access) and released when you close the file. CodePad never scans, indexes, or accesses any other files on your device.

A note on HTML preview

When you preview an HTML file, it is rendered locally by the system web renderer (WebKit). If the HTML file itself references online resources (for example, an image hosted on the web), the renderer may request those resources from the network as part of displaying the page. CodePad itself initiates no network requests and receives no data from this process.

Changes to this policy

If this policy ever changes, the updated version will be posted at this page with a new "Last updated" date.
